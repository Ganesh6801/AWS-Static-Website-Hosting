# AWS Static Website Hosting

## Objective
Host a static portfolio website using Amazon S3.

## Services Used
- Amazon S3
- Static Website Hosting
  
## Features
- Portfolio website hosted on AWS S3
- Publicly accessible through S3 Website Endpoint
- Responsive design
